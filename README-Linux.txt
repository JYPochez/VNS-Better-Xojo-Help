BETTER XOJO HELP ON LINUX

If double-clicking "Better Xojo Help" asks which application to open it with,
the program is not allowed to run. Some tools that unpack a zip leave that
permission out. Open a terminal in this folder and type:

    chmod +x "Better Xojo Help"
    ./"Better Xojo Help"

The first line is needed only once. After that, start it with the second line,
or by double-clicking if your file manager runs programs.

At its first start the app looks for installed Xojos and offers to install
their documentation. Help > Getting Started explains the rest.
